# Role comparison batch

Copy this file once per comparison, keep one to three roles, and replace the example text. `## Role:` and `## Role title:` are both accepted.

Under Responsibilities, Qualifications, In This Role, or Thrive headings, each bullet or non-empty plain line is one requirement. Keep a whole requirement on one line; indented continuation lines are supported for bullets. Preflight lets you review the detected list and optionally convert plain lines to bullets. When explicit requirement sections exist, role-summary prose is excluded; move any additional summary requirement into Responsibilities. Without explicit sections, summary prose is used instead. Common employment boilerplate is excluded, but always review the detected list before submitting.
