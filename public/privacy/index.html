Conversation privacy.

The chat is designed to improve the CV without turning visitors into profiles.

What is saved

When you use the chat, the site may save the question, the assistant's answer, a random conversation and turn identifier, the page where the question started, the model name, completion status, a coarse human-or-bot classification, and any helpful/not-helpful feedback you submit.

The application does not intentionally store your IP address in the conversation archive. It does not create advertising profiles or sell conversation data.

Why it is saved

John reviews aggregated questions and answer-quality signals to identify missing CV evidence, improve the source material, and prepare follow-up interviews with a private local AI agent. Conversation exports remain private and are not added to the public CV automatically.

Retention and processors

Cloudflare stores the rolling archive for up to 90 days, after which records expire automatically. John may create restricted local exports for the same content-improvement purpose and should delete them when no longer needed.

Chat prompts are processed by Cloudflare Workers and the OpenAI API. The chat request sets store: false to avoid Responses API application-state storage. Under OpenAI's default controls, prompts and responses may still appear in abuse-monitoring logs for up to 30 days unless approved data-retention controls apply. API content is not used to train OpenAI models by default unless the API organization opts in. See OpenAI's official usage policies by endpoint.

Transient role comparisons

The comparison workspace keeps role drafts and completed results in memory while the page is open and also uses this site's same-origin sessionStorage for the current tab when the browser permits it. If session storage is blocked, the workflow remains usable in memory but its state disappears when the page closes. Clearing the comparison removes the site-controlled comparison state in that tab. Tab duplication and browser restore behavior are controlled by your browser, however, so the site cannot promise immediate erasure from a duplicated or restored tab.

This site does not archive or persist role comparison postings or results in Cloudflare KV or in the chat archive. The site chat archive is separate and may last up to 90 days. Persistent private application links are also separate from the transient comparison workspace. The comparison's public WebMCP tool results omit human-entered role text and generated prose, although the visible page still needs that content to show the comparison.

To create a comparison, the job text is sent through a Cloudflare Worker to the OpenAI API. The OpenAI Responses call uses store: false, background: false, and no conversation object. For /v1/responses, store: false means no application-state retention; default abuse-monitoring logs may nevertheless contain prompts and responses for up to 30 days unless approved controls apply. API content is not used to train OpenAI models by default unless the API organization opts in. The same official OpenAI endpoint policy explains those controls.

If you invoke the page through a browser agent or chat product, that agent, account, or provider may retain its own prompt, history, or activity according to its workspace settings. This site does not control those separate records.

What not to submit

Please do not paste confidential job information, special-category personal data, credentials, or third-party information about another person. The public chat is intended for questions about John's professional experience, and the comparison needs only the public wording of a role.

Access or deletion

To ask about a conversation record or request deletion, use the contact route supplied with John's application or reach John through his public GitHub profile. Include the approximate date and wording of the question; do not send credentials.
